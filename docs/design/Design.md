# hima. — Design Specification

> **Version:** 0.2 (MVP)  
> **Platform:** Flutter / iOS・Android  
> **Last updated:** 2026-11-16  
> **Status:** デザイン方針。実装前に細部を調整してよい。

## 0. 2026-11-16 の決定事項

初版のあとに決まった内容です。初版と食い違う場合はこちらを優先します。

- プロダクト名は **`hima.`**（ロゴ表記）。Android の `android:label` と iOS の `CFBundleDisplayName` も `hima.`。Dart パッケージ名は `atsumaro` のまま。
- 温度感（`fire` / `ok` / `quiet`）は維持し、マッチングも温度感で決まる（fire×fire、fire×ok、ok×ok。quiet は自動マッチしない）。
- やりたいこと（activity）は Bot と同じ `game` / `chat` / `work` / `out` / `any`。**任意項目**で、未選択は null。表示は単に `ひま`。
- 宣言時間はデフォルト60分、選択肢は **30分 / 1時間 / 2時間** のみ。
- 友達は「共通の Discord サーバーのメンバー」。友達申請・追加の導線は持たない。
- `さそう` は OS 共有シートではなく**アプリ内ノック**。受信・送信はヘッダーのベルの先に置く。
- タブは `ホーム` / `友達` / `プロフィール` の3つ。設定はヘッダーの歯車からも開ける。

## 1. プロダクトの方向性

**hima.** は、友達に「いま暇だよ」と気軽に伝え、暇な友達を見つけて誘うためのアプリ。

### コア体験

1. アプリを開く。
2. 大きなボタンを1回押して、**暇であることを宣言**する。
3. 友達の「暇」状態を見て、気になる友達を誘う。

**位置情報アプリではない。** whoo / Bump から参考にするのは、友達の存在感、テンポのよいUI、明るい配色、遊び心のある表現。**地図・GPS・常時位置追跡はUIにもMVP機能にも含めない。**

### デザインのキーワード

- **Friendly:** 仲のよい友達が自然に集まる空気感。
- **Playful:** 文字の勢い、少しだけ不規則な図形、小さなリアクション。
- **Instant:** 「暇を宣言」が最も簡単で目立つ操作。
- **Human:** 写真・名前・近況を重視。無機質な設定画面の集合にしない。
- **Clear:** 派手でも見やすさと状態の分かりやすさを優先。

### 避けること

- 地図を背景にすること、現在地・距離・「近くの友達」表示。
- 画面全体をパステルのグラデーションや大量のステッカーで埋めること。
- 意味なく光るボタン、過剰なドロップシャドウ、無関係な絵文字の乱用。
- 「いま、ひま！」なのに主ボタンが「ひまを宣言」のままになるなどの**状態矛盾**。
- 宣言のたびに質問への回答を必須にすること。

## 2. 最重要コピーと状態設計

ユーザーの状態に応じて、ホーム画面の**主見出しが変わる**。

| 状態 | 主見出し | 補助文 | メイン操作 | 補助操作 |
|---|---|---|---|---|
| **未宣言** | **いま、ひま？** | 「ひまなら友達に知らせよう」 | **ひまを宣言** | 任意で「なにする？」を選択 |
| **宣言中** | **いま、ひま！** | 「あと○分くらい」 | `おわる`（小さな二次ダブ） | 残り時間・温度感・やりたいことを変更 |
| **期限切れ直後** | **いま、ひま？** | 「ひま宣言が終了したよ」※一時表示 | **ひまを宣言** | なし |

### このコピーの原則

- `いま、ひま？` は、アプリからユーザーへの気軽な問いかけ。
- `いま、ひま！` は、ユーザー自身の状態を表す宣言。
- 句読点、全角の `！` / `？` を含めて統一する。
- 状態は**色と文字の両方**で伝える。色だけで区別しない。
- 宣言中に再度「宣言」を促すボタンは配置しない。終了は小さく静かな二次ダブにし、主役は見出しに譲る。

### 宣言のルール（MVP案）

- 最初の宣言は**ワンタップ**で成立。選択項目は必須にしない。
- 宣言時間はデフォルト **1時間**。宣言後に **30分 / 1時間 / 2時間** へ変更可能。
- 時間切れで自動的に「未宣言」へ戻す。端末側の表示だけでなく、共有される状態も終了させる。
- 「なにする？」は任意。未選択の場合は `なんでもOK` に決めつけず、単に `ひま` と表示する。
- ネットワークエラー時は成功扱いしない。元の状態を保って再試行できるようにする。

### 温度感の選び方

- **タップ**:「ひまを宣言」は直前まで使っていた温度感で即宣言する（初回は `ok`）。質問を挟まない。
- **長押し**: ボタンの周りに3つの温度感バブルが弧状に飛び出す。指を重ねたバブルが 1.3 倍に広がり、離すとその温度感で宣言する。外して離すとキャンセル。
- 宣言中はヒーローに現在の温度感をタップできるバッジとして出し、タップで小さなピッカーを開いて**同じセッション ID のまま**変更する。
- 初回のホーム表示時だけ「長押しで温度感を選べるよ」をボタンの近くに表示する。

## 3. デザインシステム

### 3.1 カラーパレット

**白地 + 濃い紫の文字**をベースに、コーラルピンク・イエロー・ライムをアクセントとして使う。画像の色を再現するための**初期近似値**であり、最終的なコントラスト確認で調整してよい。

| Token | HEX | 用途 |
|---|---|---|
| `background` | `#FFFEFC` | アプリ全体の背景 |
| `surface` | `#FFFFFF` | ボトムナビ、通常カード |
| `ink` | `#2F124F` | 見出し、本文、輪郭の基調 |
| `muted` | `#756B83` | 補助文、時刻、プレースホルダー |
| `purple` | `#7538DC` | ナビ選択、アクションの強調 |
| `purpleSoft` | `#F0E3FF` | 未選択部分、友達カードの薄紫 |
| `coral` | `#FF6389` | 自分の「ひま」状態カード |
| `coralLight` | `#FF8E86` | 自分のカードの淡い変化色 |
| `yellow` | `#FFE65A` | メインCTA・注目ポイント |
| `lime` | `#C5F35C` | 「ひまな友達」の人数バッジ |
| `skySoft` | `#DDF6FF` | 友達カードの淡い水色 |
| `mintSoft` | `#DDF9E9` | 友達カードの淡い緑、`いいよ！` の下地 |
| `peachSoft` | `#FFF0DC` | 友達カードの淡いオレンジ |
| `lemonSoft` | `#FFF3BF` | `なんでもOK` の淡いイエロー |
| `success` | `#13724A` | 成功を示す濃い緑（アイコンなど。`mint` 上の本文には使わない） |
| `mint` | `#A8EFC9` | `いいよ！` のペイントダブ |
| `mutedSoft` | `#E7E3EC` | `さそった` のペイントダブ |
| `teal` / `blue` / `orange` | `#0F7E70` / `#1F6FB2` / `#B4551A` | やりたいことタグのアイコン色（通話 / 作業 / 外出） |
| `heroDeclaredTop` → `heroDeclaredBottom` | `#C2143F` → `#D0305A` | 宣言中のヒーロー（深いコーラル→ローズ）。白文字が 6.1:1 / 4.9:1 |
| `heroIdleTop` → `heroIdleBottom` | `#F2E6FF` → `#FFEFF6` | 未宣言のヒーロー（ライラック→ブラッシュ） |
| `danger` | `#D93F58` | エラーや危険な操作（必要時のみ） |

**配色の配分：** 白・生成りを約70%、状態カードや友達カードを約25%、鮮やかなアクセントを約5%の感覚で使用。実際の面積比は画面に合わせる。

**注意:** `yellow` 上の白い文字や `lime` 上の白い文字は避ける。基本は `ink` を使い、可読性を確認する。`heroDeclared*` 上の白文字は大きな太字（見出し）に限り、細かい文字は白いペイントダブに載せる。見出しの白は**グラデーションの両端で 4.5:1 を満たす**必要があるため、宣言中の塗りは淡いピンクではなく深いコーラル→ローズにしてある（`#FF4A78 → #FF9FB4` は 3.2:1 / 1.9:1 で不可）。淡いピンクを使いたくなったら、文字を `ink` に変えること。

### 3.2 タイポグラフィ

- **本文:** OS標準の日本語サンセリフ（Flutter標準）。
- **見出し:** 丸みのある日本語ゴシック。**M PLUS Rounded 1c**（SIL OFL 1.1）を `app/assets/fonts/` に同梱して使う（500 / 700 / 800）。`google_fonts` は使わず、実行時にフォントをダウンロードしない。ライセンスは同ディレクトリの `OFL.txt`。
- **ロゴ `hima.`:** 別途ロゴアセットまたは太めの丸ゴシック。本文と異なる強い個性を許可。
- 画像の文字を単純なアウトライン画像で再現せず、**アクセシブルなTextウィジェット**を優先。

| Style | 目安 | Weight | 用途 |
|---|---:|---:|---|
| `logo` | 44sp | 900 | hima. |
| `heroTitle` | 36sp | 800–900 | いま、ひま？ / いま、ひま！ |
| `sectionTitle` | 23sp | 800 | いまひまな友達 |
| `friendName` | 18sp | 800 | 友達の名前 |
| `body` | 15sp | 600 | アクティビティ、本文 |
| `button` | 17–19sp | 800 | ひまを宣言 |
| `caption` | 12–13sp | 600 | 残り時間、補助テキスト |

- 見出しはコンパクトな行高、本文はゆったりめの行高を使う。
- 絵文字は説明の補助に留める。アイコンと絵文字をむやみに重複させない。
- Flutterの文字拡大設定に追従し、最低でも200%のテキストスケールで致命的な欠けを発生させない。

### 3.3 形・余白・線

| Token | 値 | 用途 |
|---|---:|---|
| `space4` | 4dp | アイコンと文字の最小間隔 |
| `space8` | 8dp | チップ内部、短い情報間 |
| `space12` | 12dp | カード内の要素間 |
| `space16` | 16dp | 標準の画面左右余白 |
| `space24` | 24dp | セクション間 |
| `space32` | 32dp | 大きなまとまりの間 |
| `radiusCard` | 24dp | カードの下地（実際の輪郭はペイント、3.4） |
| `radiusHero` | 32dp | 自分のステータスカード（実際の輪郭はペイント、3.4） |
| `minTapTarget` | 48dp | すべてのタップ領域の下限 |

- **ホームとボトムナビでは輪郭線を使わない。** 要素の境界はペイントの形・色・余白で示す。1.5〜2dp の枠線、ヘアラインの区切り線、アウトラインのピルはホームから廃止した。`borderWidth` はまだ他の画面（友達・設定・シート）が使っているが、それらも同じキットで塗り直す対象。
- 形は**絵の具の塊**にする。角丸の矩形や完全なスタジアムではなく、縁がわずかに揺らぎ、飛沫や雫を伴う不定形（3.4）。
- 影は弱く。情報のまとまりは影よりも余白と背景色で示す。

### 3.4 ペイントキット（paint）

「ビチャ！」という絵の具の表現を、`lib/shared/widgets/paint/` の小さな `CustomPainter` プリミティブで作る。線で描いた落書き（`///`、波線、`!!`）は廃止した。

| プリミティブ | 用途 |
|---|---|
| `PaintSplat` | 主役の飛沫。ヒーローの下地、ボトムナビの選択タブの下地 |
| `PaintWash` | カード・セクションの下地。同系色の半透明ブロブを重ねた水彩の滲み |
| `PaintDab` | ボタン・ピル・チップの下地。潰れた歪な塊（`PaintSplat` の別名） |
| `BrushStroke` | 手描きの下線。中央が太く両端が細い、縁の粗いリボン |
| `SplatterDots` | 小さな飛沫の散布。`///` の代わり |
| `PaintMark` | 星・ハートの小さな飾り。線ではなく塗りつぶした塊 |
| `PaintSwash` | ボトムナビの下地。上端が揺らぐ、画面幅いっぱいの淡い滲み |

**作り方の原則**

- **極座標のブロブ。** 輪郭は角丸矩形の周を一定間隔でサンプリングし、各点を中心から見た半径方向に 2〜4 本のサイン波（seed 付きの位相・振幅）で押し広げる。点は中点を通る2次ベジェで結ぶので、多角形の角は見えない。半径の式を角度の関数として直接書くと角丸の扱いでレンズ状に潰れるため、周長サンプリングを採る。
- **seed で決める。** すべての形は `int seed`（`paintSeedOf(名前やID)`）から決まる。`Random()` を描画時に呼ばない。カードは再ビルド・ポーリング・スクロールで同じ輪郭を保ち、同じ友達はいつも同じ飛沫になる。
- **パスはキャッシュする。** (seed, サイズ, 設定) をキーに一度だけ生成して使い回す。スクロール中に輪郭を毎フレーム再サンプリングしない。
- **セーフレクト。** `child` は `padding` ぶん内側の矩形に収め、ペイントはその外側の帯まで広がる。飛沫・雫・揺らぎは必ずセーフレクトの外に置くので、文字やタップ領域を覆わない。角丸の半径は `padding` から上限を解いて決めるため、どれだけ丸くしても中身を削らない。揺らぎは外向きのみで、形がセーフレクトに食い込むことはない。
- **アニメーション低減。** 動くプリミティブは `progress`（0→1）を受け取り、`MediaQuery.disableAnimationsOf` が真なら最終状態を静止画で描く。

**モーション**

- **`PaintSplat` の `progress`。** 本体は `minScale`（既定 1）から基準サイズへ飛び込み、オーバーシュートして着地する。飛沫が縁から飛び出して所定の位置に収まり、雫が少し遅れて伸びる。
- **中身を載せる飛沫は `minScale: 1`。** 本体が 1 倍を下回らないので、アニメーション中も中身は必ずペイントの上にあり、文字のコントラストが落ちない。飛び込みを見せたいときは、不透明な塗りの上に `minScale < 1` の装飾用の飛沫を重ねる（宣言成功のヒーローがこの形）。装飾用の飛沫は塗りより**濃い**色にする。淡くすると白文字が 3.5:1 まで落ちる。
- それ以外のプリミティブは静止画。スクロールする一覧に無数のコントローラを載せない。

**置き場所**

- 装飾は余白の帯に置く。文字の上には置かない。
- 画面全体で 5〜8 箇所。均等に並べず、左右非対称に散らす。カードは全部には付けず、2〜3枚に1つ程度。
- 意味は持たせない。読み上げ対象から外し（`ExcludeSemantics`）、ポインタも無視する。色は状態を表さない。

**色**

- ペイントは単色で塗らない。2色のグラデーション（左上→右下）か、同系色の半透明の重ねで tonal variation を持たせる。
- カードの下地には、縁にわずかに濃い「溜まり」の線を `MaskFilter.blur`（半径 1.4dp 程度）で添える。枠線ではなく水彩の縁。
- ぼかしは小さく保つ。ホームは何枚もスクロールするので、大きな半径のぼかしは使わない。

**一覧・設定・セグメント**

- **一覧は枠も区切り線も持たない。** サーバーや設定のまとまりは1枚の `PaintWash`（seed はサーバーIDや項目名から取る）に載せ、行と行は余白だけで分ける。見出しの下には `BrushStroke` を敷く。
- **設定の行は Material の `Switch` のまま。** 下地だけを塗りに変え、読み上げと操作は標準から動かさない。
- **セグメント（受信／送信）は淡いトラックに白いピルを置かない。** 選択中の側にだけ紫のダブが着地し、もう片方は紙の上の文字だけにする。
- **ボタンは `PaintDab`。** 主操作は紫のダブに白文字、副次操作はインク文字の淡いダブ。洗いの上では洗いと同系色を避ける（ノックの返事は空色。ミントは「いいよ！」の色）。無効時は `mutedSoft` にインクで、文字を薄めない。
- **洗い（wash）の上の文字は一段暗くする。** パステルの洗いは重なりで濃くなるため、`muted` のままだと 4.5:1 を割る。

## 4. ホーム画面

### レイアウト順

1. **Header:** `hima.` ロゴ、通知、設定への導線。
2. **My Status Hero:** `いま、ひま？` / `いま、ひま！` が最も目立つ領域。未宣言は「見出し + 説明 + ひまを宣言 + `なにする？` チップ」、宣言中は「アバター＋見出し + メタ行 + `おわる`」（4.2）。
3. **Match Cards:** マッチした**種類ごとに1枚**（最大3枚）。
4. **Friends Section:** `いまひまな友達` と人数バッジ、友達カード。
5. **Bottom Navigation:** `ホーム` / `友達` / `プロフィール`。

**初期画面で絶対に見せるもの：** 自分の状態、宣言操作、暇な友達が何人いるか。全友達カードの表示は縦スクロール可。

### 4.0 レイアウトの決定事項（実機レビューより）

- **`なにする？` をヒーロー内へ移動。** 以前は Friends Section の下にあったため、宣言の前後でやりたいことを選ぶには友達グリッド全体をスクロールする必要があり、実質的に隠れていた。任意項目であることは変えず、未宣言では主ボタンの直下に1行の横スクロールとして置く（4.4）。
- **マッチカードは種類ごとに1枚。** 1人1枚だと 🔥 のときに4枚並び、`いまひまな友達` が画面外へ押し下げられ、しかも同じ人が下のグリッドにもう一度出ていた。カードは種類のメッセージを見出しにし、該当する友達のアバターを名前付きで横に並べる（最大5人、残りは `+N`）。種類は見出しのアイコンと文言だけで示し、アバターの横に浮かせた絵文字は置かない（誰の温度感か分からなくなるため）。温度感はアバターごとのバッジにする。
- **マッチカードも友達カードと同じ言葉で描く。** 細い枠の白い箱は、隣のヒーローや友達カードの横で入力フォームに見えていた。種類ごとにパステルの下地（🔥×🔥 はピーチ、🔥×🙂 はレモン、🙂×🙂 はスカイ）と、右上に小さな塗りダブ（`PaintMark`）を置く。見出しは種類の絵文字ペア + 一文。アバターは白いリング付きの 56dp（友達カードと同型）に温度感バッジを添え、`さそう` / `さそった` / `いいよ！` は各アバターの直下に置く。色は種類の区別を助けるだけで意味は持たせず、内容は必ず文言でも示す。
- **アバターは入るときは等間隔、入らないときは横スクロール。** 左に寄せると右半分が空いて見え、逆に縮めると下のダブが読めなくなる。入る枚数なら `spaceEvenly` で配り、超えたらスクロールさせる。
- **残り時間とやりたいことは見出しの直下の1行。** 以前はカード下部に中央寄せで浮いており、見出しと結び付いて見えなかった。宣言中は見出しの下のメタ行にまとめ、`Wrap` で大きな文字サイズでも折り返す。温度感はアバターのバッジに移した（4.2）。
- **宣言中は要素を3つに絞る。** 温度感のピル・全幅の終了ボタン・チップ列が積まれて見出しが埋もれていたため、宣言中は「アバター＋見出し」「メタ行」「`おわる`」だけにし、チップ列はメタ行の1ダブへ畳む（4.2）。`おわる` はメタ行と同じ `Wrap` に並べる。独立した行に置くと下段の左半分が空いてカードが縦に伸び、しかもダブが飛沫の右下の丸みに食い込んで切れて見えた。

### 4.1 Header

- 左：太くて丸い `hima.` のワードマーク。
- 右：通知ベル（未確認のノックや結果があると赤いドット）、設定アイコン。
- ベルのドットは、受信は一覧を表示した時点で、送信は結果を表示して既読にした時点で消える。
- ベルはノック画面（受信／送信）を開き、歯車は設定を開く。設定はプロフィールタブにも並ぶ。
- アイコンボタンのタップ領域は最低 **48×48dp**。
- ロゴ以外の装飾は少なくして、主役をステータスに譲る。

### 4.2 My Status Hero

ホームの視線の中心。自分のアバターを大きめに表示して、状態をひと目で判断できるようにする。背景は角丸の矩形ではなく、**飛沫（`PaintSplat`）**にする。未宣言は淡いライラック→ブラッシュの飛沫、宣言中はその上に**深いコーラル→ローズ**の飛沫を重ねる（白い見出しが 4.5:1 を保つ濃さ。3.1 の注意を参照）。宣言中の飛沫は未宣言のものより 3% 大きく描くので、セーフレクトは常にコーラルで覆われ、白い見出しが淡い下地に落ちることはない。淡い下地は余白の帯に薄いハローとして残り、重ねた絵の具に見える。

飛沫は縁の外側に飛沫と雫を持つが、どれもセーフレクト（内側 20dp）の外にしか置かないので、文字やタップ領域を覆わない。

**未宣言**

- 見出し：**`いま、ひま？`**（`ink`）
- 説明：`ひまなら友達に知らせよう`
- 主ボタン：**`ひまを宣言`**。イエローのペイントダブ、文字は濃い紫。長押しで温度感メニュー（2節）。
- 補助：主ボタンの直下に `なにする？` チップ（4.4）。残り時間は表示しない。

**宣言中**

「祝福のメッセージを1つ読む」だけの面にする。要素は次の3つに限る。

1. **アバター + 見出し**：アバターの右下に温度感の絵文字バッジ（26dp 表示、タップ領域は 48dp）。タップで温度感ピッカーを開く。見出しは白・数度傾けた **`いま、ひま！`**、その下に白いブラシストローク（`BrushStroke`）。
2. **メタ行（1行）**：残り時間 `あと1時間くらい` と、やりたいこと `ゲーム`（未選択なら `なにする？`）。どちらも白いペイントダブで、タップで変更できる（時間は 30分 / 1時間 / 2時間、やりたいことはシート）。
3. **`おわる`**：メタ行の最後に並べる、小さく静かなダブ。48dp のタップ領域は保つ。行を分けずに済ませるのは、下段が空いてカードが縦に伸びるのを避けるため。

- `なにする？` のチップ列は宣言中は出さない。選んだものはメタ行に1つだけ出す（4.4）。
- 温度感を独立したダブとして並べない。バッジとメタ行で足りる。
- 温度感バッジの絵文字は**文字拡大に追従させない**。円はアバターの角に載る固定サイズなので、絵文字だけが大きくなると円からはみ出して欠けて見える。温度感は読み上げラベル（`Mood.label`）が伝える。
- 全幅の終了ボタンは置かない。宣言中に「ひまを宣言」を再度促すボタンも置かない。
- 宣言直後の短いリアクションアニメーションを表示（6節）。

**重要：** 画像の赤いカード内に `いま、ひま！` と `ひまを宣言` が同居する表現は採用しない。**状態に応じた一貫したUI**へ修正する。

### 4.3 Friends Section

- セクション名：**`いまひまな友達`**。人型アイコン、ライムの人数ダブ、文字の下に紫のブラシストローク、右端に小さな飛沫（`SplatterDots`）。
- カードは原則**2列グリッド**。幅が足りない端末では1列、または縦型レイアウトへ適応。
- 友達カードの下地は**`PaintWash`**（枠線なし）。同じ色相の半透明ブロブを2〜3枚重ね、縁に淡い溜まりの線を添える。形は友達 ID から seed を取るので、再ビルドやスクロールで変わらない。
- 友達カードは、白いリング付きの丸アバター（右下に温度感の絵文字バッジ）、名前、残り時間、やりたいことのダブ、`さそう` ダブで構成。
- やりたいことのタグは**白いペイントダブ + そのカテゴリの色のアイコン**（ゲームはコントローラ、通話は電話、作業はノートPC、外出は歩く人、なんでもは星）。カードの下地はパステルで回転するため、タグの下地までパステルにすると同じ色のカードで見えなくなる。色はアイコンで示す。
- カードの2〜3枚に1枚、小さなハートや星の塗りダブを添える（3.4）。
- `さそう` は宣言中の友達にのみ表示。未宣言の友達の行動を推測する表示はしない。
- ノックを送った相手は、返事が来るまで `さそった`（チェック印・淡い下地・押せない）に変わる。二重に誘えないようにするため。
- 返事が `いいよ！` なら、その相手は**ミントのダブ**にする。以前は返事が届いた瞬間に `さそう` へ戻り、承諾されたことが画面から消えていた。この状態は**その宣言が続いているあいだだけ**保ち、`ひまを終了`・期限切れ・宣言し直しのいずれでも `さそう` に戻す（サーバーは返事を保持し続けるので、アプリ側で「今回の宣言の約束」として畳む）。
- 友達がゼロ人なら、空のグリッドの代わりに `まだひまな友達はいないよ` と案内する。
- 写真未設定の友達は、名前から選んだパステルのグラデーションにイニシャルを載せたサークルで代替する。

**`さそう` の3状態（`KnockPill`）**

| 状態 | 下地 | 文字 | コントラスト |
|---|---|---|---|
| `さそう` | `purple` のダブ | 白 | 6.3:1 |
| `さそった` | `mutedSoft` のダブ | `ink` | 12.6:1 |
| `いいよ！` | `mint` のダブ | `ink` | 12.0:1 |

**Friend Card の例**

```text
(ゆるい塊の下地。枠線なし)
  (写真)  ゆう
          あと40分
  [🎮 ゲーム]      ♡
  [     さそう     ]
```

アバターは左に大きめ（56dp + 白いリング）、名前・残り時間はその右に縦に並べ、やりたいことのダブと `さそう` はカード幅いっぱいに置く。

カードの色は友達ごとに薄紫・水色・ピーチ・ミントをローテーションしてよい。**色そのものに意味は持たせない**（状態は文字で表現）。

### 4.4 「なにする？」チップ

- 置き場所はヒーロー内、主ボタンの直下（4.0）。**未宣言のときだけ**出す。
- 候補：`ゲーム` / `雑談・通話` / `作業通話` / `外出` / `なんでもOK`（Bot と同じ値。`game` / `chat` / `work` / `out` / `any`）。
- チップは**カテゴリごとに色とアイコンを変える**（`ActivityStyle`）。同じ白いチップを並べない。下地は小さなペイントダブ。
- 選択中は**その色をアクセント方向へ寄せた濃いダブ**にし、飛沫を1〜2個添える。枠線では示さない。
- 未選択（null）を許す。API でも任意項目で、未選択は `ひま` と表示する。
- 宣言の**必須条件にはしない**。選ばなくてもすぐに宣言できる。
- 未宣言でチップを押した場合は、選択内容を保持するだけ。勝手に宣言しない。
- 宣言中はチップ列を出さず、選んだものをメタ行の1つのダブに畳む（4.2）。タップで同じ選択肢をシートに出す。宣言中に選び直した場合は、共有しているカテゴリを更新する（更新成功後に反映）。
- 一度に選択できるカテゴリは、MVPでは**1種類**。未選択に戻せる。
- チップは横スクロール可能。狭い画面でも文字を潰さない。

### 4.5 Bottom Navigation

- タブは `ホーム` / `友達` / `プロフィール` の3つ。
- **直線の帯にしない。** 背景は `PaintSwash`（画面幅いっぱいの淡い紫の滲み）で、上端が seed 付きの揺らぎを持つ。ページとナビの境目に直線もヘアラインも置かない。
- 選択中：**そのタブの色の飛沫（`PaintSplat`）をアイコンの背後に敷く**。ホームはコーラル、友達はミント、プロフィールはレモン。飛沫は小さな衛星飛沫を伴う。
- 切り替え：新しい飛沫が `progress` で飛び込み、前の飛沫は縮んで消える。`lib/shared/haptics.dart` の `selectionClick` を1回。
- 非選択中：アイコンとラベルは紙の上にそのまま。地の色は持たない。
- ラベルは常に見える。テキスト拡大は 130% で頭打ちにし、`プロフィール` が省略記号にならないようにする。
- `SafeArea` と下端インセットを保ち、各項目のタップ領域は 48dp 以上。`Semantics(selected:, button:, label:)` を付ける。
- スクロール内容とナビを分離し、ボトムナビは常に表示。

## 5. 他画面（MVPの最小限）

### 友達

- 友達 = 共通 Discord サーバーのメンバー。友達申請・追加の導線は持たない。

- 名前検索を上部に置く。
- 公開設定がオフのサーバーには `非表示` と表示する。

### プロフィール

- アバター、表示名。
- 設定（自動モードと自動宣言の温度感、通知、サーバーごとの公開、マッチングしない人、よくヒマな時間、X の利用時間から検出の Android プレースホルダー）、ログアウト。

- `さそう` タップ → 小さなボトムシートを表示。
- 友達の名前とやりたいことを表示し、テンプレ（`ゲームしない？` / `ちょっと話さない？` / `作業通話しない？`）を1つ選んで送る。
- quiet の相手には `スルーしてOK` を添える。
- 受信・送信はヘッダーのベルの先のノック画面にまとめる。受信は `いいよ！` / `あとで` / `今回はパス` で返す。送信は状態を表示し、未確認の結果は一度だけ強調してから既読にする。

## 6. モーション・リアクション

遊び心は「意味のある瞬間に1回だけ」出す。常時動く演出は使わない。

| 瞬間 | 動き | 触覚 |
|---|---|---|
| 「ひまを宣言」を押す | ダブが 0.92 倍に縮み、オーバーシュートして戻る | — |
| 宣言成功 | コーラルの塗りの上に、ひと回り濃い飛沫が 55% の大きさから「ビチャ」と飛び込み、オーバーシュートして着地して塗りに溶ける。飛沫が縁から飛び出し、雫が少し遅れて伸びる（約520ms）。見出しが「いま、ひま！」へ切り替わる | `heavyImpact` 1回 |
| 画面表示 | 飛沫・滲み・下線は静止画。スクロールする一覧に常時アニメーションを載せない | — |
| 長押しで温度感メニュー | 3つの温度感ダブが弧状に、順番をずらして弾みながら出る。ボタン以外の画面は暗くし（ink 35%）、ラベルはダブの下に白地で置く | `mediumImpact` |
| 指が別の温度感に重なる | そのダブが 1.3 倍、他は少し縮む | 変化ごとに `selectionClick` |
| 温度感の上で離す | 選んだダブがボタンへ吸い込まれてから宣言演出 | `heavyImpact` |
| 外して離す／キャンセル | ダブがすぼまって戻る | `lightImpact` |
| ひまを終了 | 色が静かに戻り、見出しが縦にスライドして切り替わる | `lightImpact` |
| チップ選択 | 小さなスケールバウンスとダブの色の切り替え（120〜180ms） | `selectionClick` |
| タブ切り替え | 新しいタブの飛沫が飛び込み、前の飛沫は縮んで消える（約420ms） | `selectionClick` 1回 |
| マッチカード出現 | スプリングでスライドイン | `mediumImpact`、120ms 空けて `mediumImpact` |
| 友達がひまになる／やめる | カードがフェード＋スライドして並び替わる | — |
| ノック送信 | 紙飛行機がシートの外へ飛んでから閉じる | `lightImpact` |
| 「いいよ！」が届く | 開いているタブの上にオーバーレイで出る（アバターがポンと出て `〇〇から いいよ！`）。小さな紙吹雪が1回だけ（1秒未満）。約3秒またはタップで消え、タップでノック画面を開く。閉じたあとも、その友達の `さそう` は `いいよ！` のまま残る | light → 80ms → light → 80ms → heavy |
| 「あとで」「今回はパス」が届く | 同じオーバーレイ。紙吹雪なし、フェードのみ | `lightImpact` 1回 |
| エラー | 対象のコントロールが横に小さく揺れる | 短い `vibrate`（または `heavyImpact` 1回） |

- 触覚は Flutter 標準の `HapticFeedback` を短い `Future.delayed` で組み合わせる。振動パッケージや音は使わない。
- 効果はすべて1回だけ。常時のキラキラ演出は使わない。
- OSの「アニメーションを減らす」設定に追従する。飛沫の飛び込みは最終状態の静止画に置き換え、タブの飛沫は即座に切り替える（触覚は残してよい）。
- Flutter 標準の `AnimatedSwitcher` / `AnimatedContainer` / `TweenAnimationBuilder` / `AnimationController` / `CustomPainter` を使う。アニメーション用パッケージは追加しない。
- 60fps を保つため、毎フレームでツリー全体を作り直さず、動く部分だけを切り出す。ペイントの形は seed から一度だけ生成してキャッシュし、`RepaintBoundary` で囲む。

### 状態モデル（概念）

```dart
enum HeroPhase { idle, declared, justExpired }

enum Mood { fire, ok, quiet }

enum Activity { game, chat, work, out, any }

class HeroState {
  final HeroPhase phase;
  final Mood mood;
  final Activity? activity; // null = 未選択（表示は「ひま」）
  final int durationMin;    // 30 / 60 / 120
  final DateTime? expiresAt;
}
```

**UIは `HeroState.phase` を単一の正とする。** 見出し・背景・ボタン・残り時間を別々のフラグで管理しない。宣言の成功/失敗・期限切れを含め、状態遷移を1か所にまとめる。

### 実装上の細かい注意

- 画面は `SafeArea` + スクロール可能な本文 + 固定ボトムナビ。
- 横幅基準は360〜430dpを優先。小さめの端末や大きな文字設定で破綻させない。
- グリッドのカード高さは内容で可変になってもよい。名前が長いときは2行または省略で対処。
- 残り時間は `expiresAt` から求め、端末時刻やバックグラウンド復帰に合わせて表示を更新。
- アバターの写真は `ClipOval` 等で丸く表示。アセット未読み込み時のフォールバック必須。
- アイコンは一貫したセットを使用。絵文字はカテゴリを示す用途に絞る。
- `ThemeData` は Material 3 を基礎にしつつ、**見た目はデフォルトのMaterial UIのままにしない**。
- ボタンのタップ可能領域は最低48×48dp。スクリーンリーダー向けに「ゆうさんを誘う」等の意味あるラベルを設定。
- 友達のステータスをネットワークから取得する場合は、ロード中・空・エラーの画面を用意する。

## 9. 優先順位

### P0 — 最初に作る

- ホームの2状態（`いま、ひま？` / `いま、ひま！`）。
- ワンタップの暇宣言・終了・期限切れ。
- 暇な友達の人数とカード一覧。
- 表示名・アバターのフォールバック。
- 友達のみへの公開、基本的なエラー表示。

### P1 — MVPが動いてから

- `なにする？` の任意カテゴリ。
- 宣言時間の変更、`さそう` の共有シート。
- 通知や軽いアニメーション。

### P2 — 後から検討

- Discordとの連携。
- 友達グループ単位の公開範囲。
- ステッカーやリアクションの種類追加。
- デザインテーマ変更。

**非スコープ:** GPS、地図、移動履歴、常時位置追跡、フルチャット機能、投稿フィード。

## 10. デザイン完了・実装受け入れ条件

- [ ] 未宣言時の主見出しが正確に **「いま、ひま？」** である。
- [ ] 宣言中の主見出しが正確に **「いま、ひま！」** である。
- [ ] 宣言中に **「ひまを宣言」** ボタンが表示されない。
- [ ] 宣言中のヒーローが「アバター＋見出し」と「メタ行（`おわる` を含む）」に収まっている（全幅の終了ボタンも、独立した温度感ダブも、`おわる` だけの行もない）。
- [ ] どのコントロールも飛沫の輪郭で切られていない。
- [ ] 「暇を宣言」はカテゴリ選択なしでも1タップで成立する。
- [ ] 残り時間が切れたら自動終了する。
- [ ] 自分の状態と友達の状態が文字で判別できる。
- [ ] 360dp幅でも文字・カード・ボトムナビが重ならない。
- [ ] 200% の文字拡大でもヒーロー・カード・チップが欠けない。
- [ ] ホームとボトムナビに、枠線・区切り線・アウトラインのストロークが残っていない。
- [ ] 形が seed で決まっており、再ビルドやスクロールで変わらない。
- [ ] アニメーション低減時、飛沫は動かず最終状態で描かれる。
- [ ] 文字サイズ拡大、スクリーンリーダー、アニメーション低減を考慮している。
- [ ] 友達の位置情報や距離を要求・表示しない。
- [ ] 「ポップ」だが、必要な操作が一瞬で見つかる。

## 11. 参考デザインとの関係

この仕様書は、会話内で作成した **カラフルな `hima.` ホーム画面モック**を視覚的な出発点とする。

- **残す:** 太い見出し、ピンクのHero、丸い写真アバター、色違いの友達カード、イエローのCTA、3タブ構成。
- **加える:** 絵の具の飛沫・滲み・雫（3.4）、カテゴリごとの色とアイコン、アバターの温度感バッジ。
- **直す:** 状態とボタン文言の矛盾、宣言中の要素の積み上げ、各カードの視認性、狭い画面への適応、直線と枠線でつながりすぎていたUI要素の分離。
- **持ち込まない:** whoo/Bumpの地図機能、位置情報共有、固有のブランドデザインやアセット、モックの写真やキャラクター。

> **最終原則:** かわいさは目的ではなく、友達が「暇ならとりあえず開く」体験を支えるための手段。最も目立つのは装飾ではなく、**自分が暇かどうか**と**友達が暇かどうか**。
